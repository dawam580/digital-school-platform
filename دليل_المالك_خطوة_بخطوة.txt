================================================================================
        دليل المالك (المورّد) خطوة بخطوة — بدون أي خبرة برمجية
================================================================================

أولاً: تنزيل البرنامج (مرة لكل إصدار)
--------------------------------------------------------------------------------
1. افتح صفحة المستودع على GitHub ← تبويب Actions.
2. اختر آخر تشغيل باسم «Build Windows Installer» بعلامة ✓ خضراء.
3. أسفل الصفحة في Artifacts نزّل «منظومة-المدرسة-الرقمية-ويندوز» (ملف zip).
4. بداخله:
   - منظومة المدرسة الرقمية-Setup-....exe   ← برنامج التثبيت (للمدارس)
   - منظومة المدرسة الرقمية-Portable-....exe ← نسخة تعمل بدون تثبيت
   - دليل_التشغيل_والترخيص_المدرسي.txt      ← يُسلَّم مع البرنامج للمدرسة

ثانياً: جهازك أنت (جهاز المورّد) — مرة واحدة
--------------------------------------------------------------------------------
1. ثبّت نفس البرنامج على حاسوبك.
2. من القائمة العلوية: مساعدة ← «استيراد مفتاح المورّد (للمالك فقط)…»
   واختر ملف private.pem (مفتاح التوقيع). يُرفض أي مفتاح لا يطابق البرنامج.
3. يُعاد تشغيل البرنامج ويصبح حاسوبك قادراً على إصدار التراخيص.
⚠️ احتفظ بنسخة من private.pem في فلاشة آمنة. لا تضعه على أي جهاز مدرسة.
   ضياعه = لا يمكن إصدار أو تجديد أي ترخيص.

ثالثاً: بيع المنظومة لمدرسة (مثل بنيان)
--------------------------------------------------------------------------------
1. أرسل للمدرسة برنامج التثبيت + الدليل المدرسي.
2. المدرسة تثبّت وتشغّل ← تظهر «بصمة الجهاز» (HWID-LY-....) ← ترسلها لك واتساب.
3. على حاسوبك: بوابة المدير العام ← التراخيص ← اسم المدرسة + البصمة + سنوي ← توليد.
4. أرسل المفتاح (MADRASA-v3-...) للمدرسة ← تلصقه ← تنشئ حساب المدير ← تعمل.
5. للتجديد كل سنة: من قائمة المدارس في نفس الشاشة زر «مفتاح سنوي 📅».

رابعاً: تطبيق أولياء الأمور على الجوال (مرة واحدة لكل مدارسك)
--------------------------------------------------------------------------------
1. أنشئ حساباً مجانياً في render.com (زر Sign in with GitHub).
2. New ← Blueprint ← اختر مستودع digital-school-platform ← Apply.
3. بعد دقائق يظهر عنوان مثل: https://madrasa-parents.onrender.com
4. في GitHub: Settings ← Secrets and variables ← Actions ← Variables ← New:
   الاسم PARENT_RELAY_URL والقيمة هي العنوان السابق. (البرنامج القادم يعرفه تلقائياً)
   أو: في كل مدرسة ← «📱 تطبيق أولياء الأمور» ← الصق العنوان ← تفعيل ← حفظ.
5. المدرسة تطبع «بطاقات دخول أولياء الأمور» ← ولي الأمر يمسح الباركود بجواله.
ملاحظة: الخطة المجانية تنام بعد 15 دقيقة بلا استخدام وتستيقظ خلال دقيقة تقريباً،
ولا تحفظ البيانات عند إعادة التشغيل — المدارس تعيد رفعها تلقائياً. عند كثرة المدارس
رقِّ الخطة (Starter) وفعّل القرص الدائم في render.yaml.

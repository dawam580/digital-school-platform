# خادم تطبيق ولي الأمر (يشغّله المورّد)

خادم واحد يخدم كل المدارس المشتركة: يقدّم تطبيق ولي الأمر (PWA يُثبَّت على الجوال)
ويستقبل من حواسيب المدارس ملخصات الطلاب **مشفّرة**.

## لماذا هو آمن

- حاسوب المدرسة يشفّر ملخص كل طالب بمفتاح مشتق من **بطاقة ولي أمره** (رقم الدخول + الرمز،
  PBKDF2 100 ألف دورة ثم AES-256-GCM). الخادم يخزن نصاً مشفّراً ومعرّف بحث فقط.
- لا يوجد على الخادم اسم طالب ولا رقم وطني ولا رمز ولا درجة مقروءة — حتى لو اختُرق.
- المدرسة ترفع بمفتاح ترخيصها (MADRASA-v3 الموقّع). مدرسة انتهى اشتراكها لا ترفع شيئاً
  (يرى أولياء الأمور آخر بيانات وصلت) — نفس نموذج بنيان في التجديد.
- مدرسة لا تستطيع الكتابة فوق بيانات طالب مسجّل باسم مدرسة أخرى.
- رسائل ولي الأمر (محادثة، تأكيد استدعاء، عذر) مشفّرة بنفس المفتاح، والمدرسة تتحقق منها
  قبل تطبيقها. العذر يصل كتنبيه للمراجعة ولا يغيّر سجل الحضور.

## التشغيل

المتطلبات: Node.js 18 أو أحدث، ونطاق عليه HTTPS (إلزامي: أدوات التشفير في المتصفح لا تعمل بدونه).

```bash
npm ci
npm run build:parent            # يبني التطبيق في dist-parent/
PORT=8787 DATA_DIR=/var/lib/madrasa-relay node server/parent-relay.mjs
```

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | 8787 | منفذ الخادم |
| `DATA_DIR` | `./relay-data` | مجلد البيانات المشفّرة (ملف لكل مدرسة) — خذ له نسخة احتياطية |
| `STATIC_DIR` | `./dist-parent` | ملفات التطبيق |
| `LICENSE_PUBLIC_KEY_HEX` | من `src/services/licensing/licensePublicKey.ts` | المفتاح العام للتحقق من تراخيص المدارس |

### HTTPS عبر Caddy (مثال)

```
parents.example.ly {
    reverse_proxy 127.0.0.1:8787
}
```

### تشغيل دائم (systemd)

```
[Service]
WorkingDirectory=/opt/madrasa
Environment=PORT=8787 DATA_DIR=/var/lib/madrasa-relay
ExecStart=/usr/bin/node server/parent-relay.mjs
Restart=always
User=madrasa
```

## ربط المدارس

1. ابنِ نسخة المدارس بعنوان خادمك: `VITE_PARENT_RELAY_URL=https://parents.example.ly npm run dist:win`
   (أو تكتبه المدرسة يدوياً في «📱 تطبيق أولياء الأمور»).
2. في المدرسة: لوحة المدير ← «📱 تطبيق أولياء الأمور» ← تفعيل ← حفظ.
3. اطبع «بطاقات دخول أولياء الأمور» من جديد: الباركود يفتح التطبيق ويضيف الابن مباشرة.

ولي الأمر: يمسح الباركود ← «إضافة إلى الشاشة الرئيسية» ← يصبح تطبيقاً على هاتفه.
يمكنه إضافة أكثر من ابن (لكل ابن بطاقته)، والخروج يمسح البطاقة من الهاتف.

## واجهات الخادم

| الطلب | من | الوصف |
|---|---|---|
| `GET /v1/view/:lid` | التطبيق | الملخص المشفّر لابن واحد |
| `POST /v1/inbox/:lid` | التطبيق | رسالة مشفّرة للمدرسة (حد يومي لكل بطاقة) |
| `POST /v1/publish` | المدرسة (ترخيص) | رفع الملخصات المتغيرة فقط |
| `POST /v1/prune` | المدرسة (ترخيص) | القائمة الحالية: يُحذف ما ألغته المدرسة (طالب حُذف أو رمز جديد) |
| `GET /v1/inbox?after=` · `POST /v1/inbox-ack` | المدرسة (ترخيص) | سحب رسائل أولياء الأمور ثم حذفها من الخادم |
| `GET /v1/school-status` | المدرسة (ترخيص) | عدد الطلاب المرفوعين والرسائل المعلقة |
| `GET /v1/health` | المراقبة | فحص الحياة |

================================================================================
           📋 دليل التسليم للمدارس والزبائن - منظومة المدرسة الرقمية
================================================================================

هذا الدليل يوضح لك كمسوق ومبرمج ومطور خطوة بخطوة كيف تسلم المنظومة للمدارس
الجديدة وتدير اشتراكاتها باحترافية وأمان كامل (على غرار منظومة بنيان):

--------------------------------------------------------------------------------
💼 1. التسليم لمدرسة جديدة (الاستلام من جهة المدرسة)
--------------------------------------------------------------------------------
1. على جهازك: npm run dist:win ثم node scripts/package-client.cjs
   (يرفض الفحص الحزمة إن كان المفتاح العام المضمَّن لا يطابق مفتاح توقيعك).
2. سلّم للمدرسة: ملف التشغيل من dist-electron + دليل_التشغيل_والترخيص_المدرسي.txt
   فقط. هذا الدليل ومجلد ‎~/.madrasa-license لا يُسلَّمان أبداً.
3. عند أول تشغيل على حاسوب المدرسة تظهر شاشة التفعيل وفيها «بصمة هذا الجهاز»
   (مثل HWID-LY-9A2F-4E10-7C3B) مع زر نسخ وزر إرسال عبر واتساب إليك.
4. يمكن للمدرسة بدلاً من ذلك أن تبدأ تجربة مجانية 7 أيام (مرة واحدة لكل جهاز).

--------------------------------------------------------------------------------
🔒 2. بعد انتهاء التجربة أو الاشتراك
--------------------------------------------------------------------------------
- تُقفل المنظومة دون حذف أي بيانات، وتعرض شاشة القفل بصمة الجهاز وزر واتساب.
- عند لصق مفتاح التجديد تفتح المنظومة مباشرة وكل البيانات كما هي.

--------------------------------------------------------------------------------
🔑 3. إصدار المفتاح (جهاز المورّد فقط)
--------------------------------------------------------------------------------
مرة واحدة في عمر المنتج: npm run license:keygen  (احفظ نسخة من private.pem في مكان آمن؛
فقدانه = لا يمكن إصدار أو تجديد أي ترخيص).

الطريقة أ — من الواجهة:
1. شغّل: npm run owner  ثم ادخل برمز الماستر (يُعيَّن أول مرة، 6 أرقام على الأقل).
2. تبويب «التراخيص»: اسم المدرسة + بصمة الجهاز (إلزامية) + النوع + هاتف المدير
   ← [توليد]. المفتاح مقيد بتلك البصمة ولا يعمل على أي حاسوب آخر.
3. للتجديد: في قائمة المدارس العميلة زر «مفتاح سنوي 📅» أو «مفتاح تمديد 7 أيام ⏳»
   يصدر مفتاحاً جديداً لنفس البصمة بنقرة واحدة.
4. «وسم كملغى» يغيّر السجل لديك فقط — المفتاح المسلَّم يبقى صالحاً حتى تاريخ انتهائه
   (المنظومة تعمل بدون إنترنت). لذلك لا تُصدر مفاتيح دائمة إلا عند الدفع الكامل.

الطريقة ب — سطر الأوامر:
  npm run license:issue -- --school "مدرسة النور" --hwid HWID-LY-XXXX-XXXX-XXXX --type annual --phone 0912345678

كل مفتاح يُسجَّل في ‎~/.madrasa-license/issued-licenses.jsonl، ومنه تُبنى قائمة
المدارس العميلة وتواريخ انتهائها في لوحة المورّد.

بعد لصق المفتاح عند المدرسة: يطلب النظام إنشاء حساب المدير (الهاتف من الترخيص
إن وُجد + كلمة مرور قوية) ثم يدخل لوحة المدير مباشرة. لا توجد كلمات مرور افتراضية.

--------------------------------------------------------------------------------
📱 تطبيق أولياء الأمور (خادم واحد لكل مدارسك)
--------------------------------------------------------------------------------
- شغّل خادمك مرة واحدة: انظر server/README.md (Node + HTTPS + Caddy).
- ابنِ نسخة المدارس بعنوانه: VITE_PARENT_RELAY_URL=https://نطاقك npm run dist:win
- الخادم يقبل فقط المدارس ذات الترخيص الساري — انتهاء الاشتراك يوقف تحديث التطبيق.
- البيانات مشفّرة طرف لطرف ببطاقات أولياء الأمور: لا تستطيع أنت ولا من يخترق الخادم قراءتها.

--------------------------------------------------------------------------------
🛡️ 4. فحص الأمان والخصوصية بين الأدوار والواجهات:
--------------------------------------------------------------------------------
- ✅ واجهة المدير العام: معزولة بكلمة مرور ورمز PIN مع حظر التخمين (Brute-Force Lockout) بعد 3 محاولات خاطئة.
- ✅ واجهة المعلم: مقيدة بكود المعلم السري، ولا يرى سوى فصوله ومواده دون صلاحية تغيير الإعدادات المدرسية العامة.
- ✅ واجهة الكنترول: معزولة برقم الهاتف ورمز الأمان لرصد شيت الامتحانات (أعمال 40 + امتحان 60) وطباعة الكشوفات، وتُنشر النتيجة لأولياء الأمور بعد الاعتماد فقط.
- ✅ واجهة ولي الأمر: دخول بالرقم الوطني للطالب + رمز ولي أمر سري من 6 أرقام (بطاقة ولي الأمر)، ولا يرى إلا أبناءه وإشعاراتهم ومحادثاتهم الخاصة.
- ✅ لا كلمات مرور افتراضية ولا أزرار دخول فوري في نسخة المدرسة؛ ومعاملات الرابط (?role=...) لا تمنح أي صلاحية.
- ✅ عدة مدارس على جهاز واحد: بيانات كل مدرسة معزولة تماماً، وكل مدرسة تحتاج ترخيصها.
- ✅ حماية ساعة النظام (Anti-Clock-Tampering): فحص ذكي يمنع التحايل عبر ترجيع تاريخ الويندوز.
